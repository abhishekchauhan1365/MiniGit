How MiniGit Stores Data

BLOB File Content Storage

Stores raw byte content compressed with zlib. Does not store filename, permissions, or path. Identical files across different directories share the exact same blob.

TREE Directory Structure

Maps filenames and permissions to Blob hashes or nested Tree hashes. Represents directory states without duplicating content.

COMMIT Immutable Snapshot

Points to a top-level Tree hash, parent commit hash(es), author info, timestamp, and message. Chains together into a Directed Acyclic Graph (DAG).

REFS & HEAD Branch Pointers

A branch is simply a 41-byte text file in .mgit/refs/heads/ containing the latest commit's SHA-1. HEAD points to the active branch.
